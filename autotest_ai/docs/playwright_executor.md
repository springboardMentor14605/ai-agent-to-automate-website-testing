# 📄 playwright_executor.py — Documentation

## Purpose

`playwright_executor.py` is the **browser automation engine** of AutoTest AI. It takes the structured test steps generated by the LLM and executes them in a real headless Chromium browser using Microsoft Playwright.

---

## Class — `PlaywrightExecutor`

### Constructor

```python
PlaywrightExecutor(headless: bool = True)
```

| Parameter | Default | Description |
|---|---|---|
| `headless` | `True` | Run browser invisibly in background. Set `False` to watch the browser during debugging. |

---

### `execute_test(test_steps, step_details) -> dict`

The main method. Launches a browser, runs all steps, and returns a results dictionary.

**Parameters:**
- `test_steps` — list of step dicts from `enriched_steps` (used to drive actions)
- `step_details` — list of step dicts from `step_details` (updated with PASS/FAIL status)

**Returns:**
```python
{
    "status":         "PASS",   # overall — PASS only if ALL steps pass
    "steps_executed": 4,        # count of steps attempted
    "error":          None,     # last error message if any step failed
    "steps":          [...]     # step_details updated with status + error
}
```

**Important behaviour — continues on failure:**
If a step fails, execution does **not stop**. The step is marked `FAIL` with its error message, and the next step runs. This gives a complete picture of which steps passed and which failed.

```python
try:
    self._execute_step(page, step)
    results["steps"][i]["status"] = "PASS"
except Exception as e:
    results["status"] = "FAIL"
    results["steps"][i]["status"] = "FAIL"
    results["steps"][i]["error"] = str(e)
    # continues to next step
```

---

### `_execute_step(page, step)` *(private)*

Executes a single step based on its `action` field.

#### Supported Actions

| Action | What happens | Key parameters |
|---|---|---|
| `open` | Navigates to URL | `target` = full URL, timeout 15s, waits for DOM |
| `fill` | Types text into input | `target` = CSS selector, `value` = text to type |
| `click` | Clicks an element | `target` = CSS selector, timeout 15s |
| `wait` | Pauses for 1 second | Fixed 1000ms delay |

After performing the action, all assertions in `step["assertions"]` are evaluated via `_run_assertion()`.

#### Example step dict:
```python
{
    "action":     "fill",
    "target":     "#username",
    "value":      "student",
    "assertions": ["expect(page.locator('#username')).to_have_value('student')"]
}
```

---

### `_run_assertion(page, assertion: str)` *(private)*

Evaluates a Playwright assertion string safely.

```python
local_scope = {"expect": expect, "page": page, "re": re}
eval(assertion, {"__builtins__": {}}, local_scope)
```

**How it works:**
- Uses Python's `eval()` to execute the assertion string
- The scope is **sandboxed** — `__builtins__` is empty, so only `expect`, `page`, and `re` are accessible
- Assertions are LLM-generated strings like `expect(page.locator("#id")).to_be_visible()`

**On failure:**
```python
raise AssertionError(f"Assertion failed [{assertion}]: {str(e)}")
```
The error message includes the full assertion string, making it easy to debug which check failed.

#### Supported Playwright assertion methods:
```python
expect(page).to_have_url("https://...")
expect(page).to_have_title("...")
expect(page.locator("#id")).to_be_visible()
expect(page.locator("#id")).to_have_value("text")
expect(page.get_by_text("text")).to_be_visible()
expect(page.locator("x").first).to_be_visible()
```

## Browser Lifecycle

```python
with sync_playwright() as p:
    browser = p.chromium.launch(headless=True)
    context = browser.new_context()
    page    = context.new_page()
    try:
        # run all steps
    finally:
        browser.close()   # always closes, even if steps fail
```

The `finally` block guarantees the browser is always closed cleanly, preventing zombie processes.

## Standalone Usage

The file can be run directly for testing:

```python
if __name__ == "__main__":
    with open("llm_generated_steps.json", "r") as f:
        test_steps = json.load(f)

    executor = PlaywrightExecutor(headless=True)
    result = executor.execute_test(test_steps)
    print(result)
```
